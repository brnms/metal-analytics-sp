# 🎸 Metal Analytics SP

A data-driven venue recommendation tool for heavy metal concert organizers in São Paulo, Brazil.

## 📌 Overview

This project analyzes global vs. local Spotify listener data for metal bands to estimate ticket-buying attendance and match artists with the most suitable venue capacity in São Paulo (ranging from intimate clubs like *La Iglesia* to major arenas like *Nubank Parque*).
